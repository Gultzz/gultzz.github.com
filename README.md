# Gustavo Schultz — Portfolio

Currículo digital bilíngue construído com Next.js App Router e TypeScript.

## Desenvolvimento

```bash
npm install
npm run dev
```

Rotas principais: `/pt` e `/en`.

## Validação

```bash
npm run lint
npm run typecheck
npm run build
```

Defina `NEXT_PUBLIC_SITE_URL` no ambiente de produção para sobrescrever a URL canônica padrão (`https://gultzz.github.io`).

Para ativar a verificação automática dos buscadores, configure também:

```bash
GOOGLE_SITE_VERIFICATION=seu-token-google
BING_SITE_VERIFICATION=seu-token-bing
NEXT_PUBLIC_SITE_LAST_MODIFIED=2026-08-13
```
